# Мини-приложение

React + Vite + TypeScript. Одна кодовая база на мобильный и десктопный клиент
MAX (ТЗ 0.2), адаптивная вёрстка, ввод мышью и клавиатурой наравне с touch.

```bash
pnpm --filter miniapp dev          # dev-сервер на :5173
pnpm --filter miniapp test         # юнит-тесты (vitest)
pnpm --filter miniapp test:e2e     # e2e (playwright), профили desktop и mobile
pnpm --filter miniapp build        # tsc --noEmit + сборка в dist/
```

Из корня монорепо то же самое доступно через `make dev-front`, `make test-front`,
`make test-e2e`.

## Стек

Зафиксирован тех. ТЗ 8.1. Отклонения от текста ТЗ, разрешённые его же оговоркой
про «рабочие ориентиры»:

| В ТЗ                          | Взято      | Почему                                                                      |
| ----------------------------- | ---------- | --------------------------------------------------------------------------- |
| React 18                      | React 19   | 19 — текущая версия; 18 отстаёт на мажор                                    |
| React Router v6 (data router) | v7         | прямой преемник того же data-router API                                     |
| Tailwind CSS                  | Tailwind 4 | конфигурация в CSS через `@theme` — ровно то, что нужно для токенов Organic |
| TypeScript последний          | 6.0        | `typescript-eslint` пока не поддерживает 7.x                                |

`@maxhub/max-ui` не используем: продукт реализует дизайн-систему Organic
пиксель в пиксель, а готовый UI-кит платформы навязал бы чужой визуальный язык
(тех. ТЗ 9.7). Требование этого пакета к React 19 на выбор версии, таким
образом, не влияет.

## Состояние

Есть: сборка, dev-сервер, юнит-тесты, e2e-обвязка на двух профилях устройств,
чтение конфигурации из переменных Vite, временный экран проверки связи с Core
API.

`src/App.tsx` — заглушка каркаса. На шаге «оболочка фронта» она заменяется на:

- токены Organic в теме (`@theme` из `docs/design/source/organic-tokens.css`),
  шрифты Caprasimo и Figtree;
- `AppLayout` с безусловной кнопкой «Главное меню» и кнопкой профиля;
- дерево из 16 роутов (тех. ТЗ 8.3);
- e2e-обход всех роутов с проверкой кнопки «Главное меню» — обязательный тест,
  который не откладывается (тех. ТЗ 9.5).

## Правила

Полный список — в [`CONTRIBUTING.md`](../../CONTRIBUTING.md), раздел
«Фронтенд». Коротко:

- server state — только TanStack Query; Zustand копий серверных данных не
  хранит;
- черновики (баллы ЕГЭ, дедлайны, позиция) переживают выход в меню через
  `sessionStorage`; прогресс профориентационного теста — намеренно нет;
- хексы не хардкодятся, только переменные темы;
- `dangerouslySetInnerHTML` запрещён правилом eslint;
- `focus-visible` обязателен на всех интерактивных элементах.

## E2E в окружениях с предустановленным браузером

Обычно браузеры ставит `pnpm exec playwright install`. Если в окружении уже есть
Chromium другой версии сборки, путь к нему передаётся переменной — загрузка не
потребуется:

```bash
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/opt/pw-browsers/chromium pnpm --filter miniapp test:e2e
```

## Типы API

Пишутся не руками, а генерируются из схемы OpenAPI живого Core API (тех. ТЗ 8.6):

```bash
make api-types     # ждёт Core API на localhost:8000
```
