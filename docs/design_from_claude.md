# Handoff: «Навигатор» — мини-приложение для MAX

## Overview

Образовательный сервис «Навигатор» для мессенджера MAX (хакатон MAX × Минобрнауки, трек «Образовательные решения»). Мини-приложение открывается внутри мессенджера и покрывает восемь функциональных блоков ТЗ плюс профиль пользователя: профориентационный тест, подбор вуза по баллам ЕГЭ, трекер конкурсных списков, расписание и дедлайны, вопросы старшекурсникам, рейтинг активности, точки питания рядом с вузом, поддержка.

Полное ТЗ — в файле `TZ_navigator_bot.md` рядом с этим README. Оно первично: если README и ТЗ расходятся, прав ТЗ.

## About the Design Files

Файлы в этом бандле — **дизайн-референс, сделанный в HTML**. Это прототип, показывающий внешний вид и поведение, а **не продакшн-код для копирования**.

Задача: **воссоздать эти экраны в целевом окружении проекта** (React / Vue / нативный клиент MAX Mini App SDK — что уже используется), опираясь на его существующие паттерны, роутинг и библиотеки. Если окружения ещё нет — выбрать подходящий стек и реализовать дизайн в нём.

`Navigator Mini App.dc.html` — самодостаточная страница: откройте её в браузере (нужны соседние `support.js` и папка `_ds/`), чтобы кликать реальные флоу. Логика внутри написана императивно через DOM ради скорости прототипирования — в продакшене это должно стать нормальными компонентами с состоянием.

## Fidelity

**High-fidelity.** Цвета, типографика, отступы, радиусы, состояния и анимации финальные — воссоздавать пиксель в пиксель. Данные (вузы, баллы, имена, точки питания) — вымышленные плейсхолдеры, их заменяют реальные источники.

### Типографика

- Заголовки / числа: `Caprasimo` (`--font-heading`), weight 400.
- Текст и интерфейс: `Figtree` (`--font-body`), 400/600/700.
- Крупная величина экрана: 104–132px, `line-height: .86–.92`, `letter-spacing: -.055em`, flush-left.
- Заголовки карточек: 19–26px Caprasimo, `letter-spacing: -.02…-.03em`.
- Основной текст: 14–15px Figtree, `line-height: 1.4–1.5`.
- Служебные caps-лейблы: 10–13px, weight 700, `letter-spacing: .16–.2em`, uppercase.
- Мелкие подписи: 11–12px.
- `text-wrap: pretty` на всех абзацах.

### Радиусы, обводки, тени

- Кнопки, инпуты, чипы, точки: `border-radius: 999px` (пилюли и круги).
- Карточки-строки списков: 26px. Крупные карточки: 28–34px. Шторка: `42px 42px 0 0`. Корпус приложения: 46px (десктоп), 0 (мобильный).
- Обводка везде `1.5px solid var(--color-neutral-400)`; пунктирная 1.5px — блок верификации почты.
- Тень корпуса: `0 30px 80px rgba(32,30,29,.28)`; шторка: `0 -30px 60px rgba(32,30,29,.22)`.
- Никаких острых углов, градиентов и второй тени.

### Сетка и отступы

- Ширина приложения 440px, `max-width: 100vw`; высота `min(100dvh, 940px)`.
- Горизонтальные поля контента 22px, верхнее 24px, нижнее 28px.
- Нижняя панель 82px (включая градиентную растушёвку фона), контент скроллится под ней.
- Вертикальный ритм между блоками: 10–12px внутри группы, 18–26px между смысловыми группами.

### Иконки

Lucide, `stroke-width: 2.75`, размеры 15–21px. Использованы: chevron-left / chevron-right, home, user, check, plus, x, bell, heart, arrow-up.

## Responsive

Одна колонка, два состояния:

- **Мобильный (`max-width: 520px`)** — `width: 100vw`, `height: 100dvh`, радиус 0, тень убрана. Фон страницы = фону приложения.
- **Десктоп** — колонка 440px по центру окна, радиус 46px, тень, вокруг фон `--color-neutral-300`.

Промежуточных брейкпоинтов нет: мини-приложение в мессенджере всегда узкое. Минимальный тач-таргет 34px (точки календаря), основные кнопки 44–54px.

## Экраны

Всего 16 экранов (`[data-scr="..."]` в прототипе). Навигация — переключение видимости панелей, каждая с анимацией входа `nvIn .34s cubic-bezier(.3,1,.4,1)` (fade + сдвиг снизу 12px).

### 1. `menu` — Главное меню

Точка входа и точка возврата.

- **Шапка**: круглый логотип 34px (`--color-text` фон, буква «Н» Caprasimo 15px в `--color-neutral-200`) + caps-подпись «НАВИГАТОР» 12px/.2em. Справа — пилюля статуса (обводка, 10px/.16em caps): АБИТУРИЕНТ / ШКОЛЬНИК / СТУДЕНТ.
- **Календарь-решётка** (главный элемент экрана, заменяет привычную сводку):
  - Крупное число выбранного дня 128px Caprasimo слева, день недели 26px справа.
  - Месяц (13px/.2em caps) и год (13px/.2em, `--color-neutral-500`) слева; справа две круглые кнопки-стрелки 38px с обводкой.
  - Шапка недели ПН…ВС, 10px, `--color-neutral-500`, grid 7 колонок.
  - Решётка точек: grid 7 колонок, `gap: 11px`, точка 34px круглая. Появление — `nvPop .34s cubic-bezier(.25,1.4,.45,1)` со stagger 12ms на день. Hover — `scale(1.16)`, 200ms.
  - **Состояния точки**: сегодня — заливка `--color-accent`; есть события — заливка `--color-text`; прошедший пустой — `--color-neutral-300`; будущий пустой — прозрачный с обводкой.
  - Пустые ячейки в начале месяца — под первый день недели (`first` в данных месяца).
  - Подпись-подсказка 12px, текст зависит от статуса.
- **Список разделов**: 8 строк-кнопок (обводка, radius 26px, padding 16/18). В строке: круг 30px с номером «01»…«08» Caprasimo 13px, название 15px, опционально акцентная плашка-бейдж (`+52` у трекера), шеврон.
  - Заблокированный раздел (4 и 7 без статуса «Студент»): круг гасится до `--color-neutral-400`/`--color-neutral-600`, под названием caps-подпись «НУЖЕН СТАТУС СТУДЕНТА» 10px. Строка остаётся кликабельной и ведёт на экран-гейт, а не показывает отказ.
- **Кнопка «Мой профиль»**: сплошная акцентная, radius 26px, иконка user + шеврон.

### 2. `profile` — Мой профиль

Единственный источник правды о пользователе (ТЗ 1.3).

- Крупное имя 66px Caprasimo.
- **Сегмент статуса**: три пилюли в ряд (`flex: 1` каждая), активная — заливка `--color-text` + текст `--color-neutral-200`.
- **Тост при смене статуса**: плашка `--color-accent-200`, radius 22px, текст 13px, анимация `nvIn .4s`. Тексты:
  - → Студент: «Статус изменён на «Студент» — открылись «Расписание и дедлайны» и «Где покушать».»
  - Студент → другой: «…«Расписание» и «Где покушать» скрыты, данные сохранены.»
  - Иначе: «Статус изменён на «X». Доступны тест, подбор вуза и трекер.»
- **Поля**: ВУЗ (кнопка «Изменить» → шторка выбора), ГРУППА (только у студента, `display: none` иначе), РЕЗУЛЬТАТ ТЕСТА (кнопка «Пройти»), ОТСЛЕЖИВАЕТСЯ ВУЗОВ (кнопка «Открыть»). Строка: caps-лейбл 10px + значение 15px + кнопка-пилюля справа.
- **Тёмная карточка баллов**: «БАЛЛЫ АКТИВНОСТИ» + число 76px + «7 МЕСТО В ВУЗЕ» + акцентная плашка статуса месяца «НАШ ЧЕЛОВЕК» и подпись «до 1 сентября».
- **Блок верификации** (только у студента): пунктирная обводка, текст про учебную почту + кнопка «Подтвердить» → превращается в плашку «ГОТОВО», обводка становится акцентной.

### 3. `test` — Профориентационный тест (блок 1)

- Номер вопроса 118px Caprasimo + «ИЗ 10».
- Прогресс: 10 полосок `flex: 1`, высота 5px, radius 999px — пройденные `--color-text`, текущая `--color-accent`, будущие `--color-neutral-400`.
- Текст вопроса 25px Caprasimo, `line-height: 1.15`.
- 3 варианта-кнопки (обводка, radius 26px, 15px текст), появление stagger 50ms.
- По клику: вариант заливается акцентом, через 180ms — следующий вопрос; после 10-го — экран результата.
- Внизу пояснение: прогресс не сохраняется при выходе (ТЗ 1.3).
- 10 вопросов зашиты в массив `QUESTIONS` в прототипе — тексты переносить дословно.

- «ВАШЕ НАПРАВЛЕНИЕ №1» + название направления 46px Caprasimo.
- Тёмная карточка: процент совпадения 62px (знак % — 26px), кикер «СОВПАДЕНИЕ», обоснование 14px, две кнопки в ряд: «Показать вузы» (акцент, ведёт в блок 2) и «Вакансии» (обводка на тёмном, открывает шторку со списком из открытого API).

- «Сохранить в профиль» — тёмная кнопка; после нажатия становится акцентной с текстом «Сохранено в профиль · +50 баллов» и начисляет баллы (блок 6).

### 5. `ege` — Подбор по баллам ЕГЭ (блок 2)

- Сумма баллов 118px Caprasimo (живо пересчитывается) + «СУММА БАЛЛОВ».
- Чипы предметов (8 штук), мультивыбор: выбранный — заливка `--color-text`.
- Для каждого выбранного предмета — строка с названием и круглым инпутом 96px (Caprasimo 22px, центр).
- **Валидация**: только 0–100. Вне диапазона — обводка инпута `--color-accent` + подпись «0–100», значение не засчитывается.
- Кнопка «Подобрать вузы» неактивна (серая, `cursor: not-allowed`, текст «Выберите минимум 3 предмета и введите баллы»), пока не выбрано ≥3 предмета с валидными баллами.
- Введённые баллы **не теряются** при выходе в меню и возврате в рамках сессии (ТЗ 2.4, 3).

### 6. `ege-res` — Шансы

- Сумма 104px + пояснение про открытые данные приёмных кампаний.
- Список вузов, отсортированный по шансу. Карточка: caps-метка шанса + индикатор из трёх точек 9px, название 24px Caprasimo, направление 13px, проходной прошлого года 12px.
- **Метки шанса вместо светофора ТЗ** (🟢/🟡/🔴 заменены, чтобы не вводить чужие цвета): ВЫСОКИЙ ШАНС — 3 акцентные точки, карточка тёмная; ПОГРАНИЧНЫЙ — 2 точки; МАЛОВЕРОЯТНО — 1 точка, карточка с обводкой. Если в вашем проекте светофор обязателен — согласуйте с дизайнером.
- Правило расчёта в прототипе: `сумма − проходной ≥ 8` → высокий; `≥ −10` → пограничный; иначе маловероятно.
- Появление карточек stagger 60ms.

### 7. `vuz-card` — Карточка вуза

- Метка шанса в шапке, название 44px Caprasimo, направление 14px.
- Сетка 2×2: БЮДЖЕТ (тёмная карточка, число 40px + «мест»), ПЛАТНО (число + «тыс ₽ / год»), ОБЩЕЖИТИЕ (Есть/Нет, 30px), ПРИЁМ ДО (дата, 30px).
- «Отслеживать этот вуз» — акцентная кнопка; если вуз уже в списке, становится прозрачной с обводкой и текстом «Уже отслеживается». После добавления — переход в трекер.

### 8. `track` — Трекер конкурсных списков (блок 3)

- Число отслеживаемых вузов 118px + подпись.
- Карточки вузов: с известной позицией — тёмные, с крупным числом позиции 44px справа; без позиции — с обводкой и шевроном, кикер «ПОЗИЦИЯ НЕ УКАЗАНА».
- **Пустое состояние** (ТЗ 3.3): текст-объяснение + акцентная кнопка «Подобрать вуз» → блок 2.

### 9. `track-det` — Позиция в списке

Два состояния одного экрана.

- **Позиция неизвестна**: заголовок 40px «На каком вы месте в списке?», пояснение, круглый числовой инпут (Caprasimo 30px), кнопка «Сохранить позицию». Пустой/некорректный ввод — акцентная обводка.
- **Позиция известна**: «ВАША ПОЗИЦИЯ СЕГОДНЯ» + число 132px + акцентная плашка с иконкой стрелки вверх и дельтой («на 52»). Текст сравнения: «Вчера вы были 116-м. Ориентировочный проходной — 78 место, вы внутри.»
- Тёмная карточка «ДИНАМИКА ЗА НЕДЕЛЮ»: 7 столбиков (`flex: 1`, скругление сверху), последний акцентный, подписи ПН…ВС 10px.
- Строка про push: круг 34px с обводкой акцента и иконкой колокольчика + текст «Напомню за 7 дней до старта приёма и за 1 день до конца» (ТЗ 3.7).
- Кнопка «Обновить позицию вручную» возвращает экран в состояние ввода.

### 10. `gate` — Раздел требует статуса «Студент»

Показывается вместо блоков 4 и 7, если статус ≠ Студент (ТЗ 1.3, 4.2, 7.2). Не отказ, а маршрут: слово «Почти» 116px Caprasimo, объяснение (текст разный для расписания и еды), акцентная кнопка «Перейти в профиль».

### 11. `sched` — Расписание и дедлайны (блок 4)

### 14. `rating` — Рейтинг активности (блок 6)

- Баллы 118px + «БАЛЛОВ / 7 МЕСТО».

- Первая (лучшая) точка — тёмная карточка, остальные — с обводкой.

- **Магазин**: caps «МАГАЗИН», название, чипы «Выпечка есть» (тинт `--color-accent-200`) и «Ассортимент средний» (обводка), шкала близости, адрес, ссылка.

### 16. `support` — Поддержка (блок 8)

- Заголовок «Что случилось?» 52px Caprasimo.
- Три чипа типа обращения; активный — заливка `--color-text`.

- После отправки — тёмная карточка «ПОДДЕРЖКА» с типовой отпиской, выбранной случайно из пула для этого типа (по 5 вариантов на тип, тексты в прототипе — переносить дословно), анимация `nvIn .36s`.

### Сквозной элемент: нижняя панель

Фиксирована внизу, высота 82px, фон — вертикальный градиент от прозрачного к `--color-neutral-200` (34%), чтобы контент уходил под неё мягко.

- Кнопка «Главное меню» — `flex: 1`, высота 54px, тёмная пилюля с иконкой home. **Присутствует на всех 16 экранах без исключений** (ТЗ 1.1).
- Кнопка профиля — круг 54px; активна на экране профиля (заливка), иначе обводка.

### Сквозной элемент: шторка (bottom sheet)

Один переиспользуемый компонент. Затемнение `rgba(32,30,29,.45)` по клику закрывает. Панель: `border-radius: 42px 42px 0 0`, `max-height: 74%`, ручка 46×5px, caps-заголовок, скроллируемое тело. Анимация `transform: translateY(101% → 0)`, `.42s cubic-bezier(.3,1.05,.4,1)`.

Используется для: событий дня в календаре, выбора вуза, выбора группы, списка вакансий, добавления дедлайна.

## Interactions & Behavior

- **Закольцованная навигация** (ТЗ 1.1) — главное требование: тупиковых экранов нет, кнопка главного меню видна всегда, переход в меню ничего не сбрасывает.
- **Гейт вместо отказа**: попытка открыть блок 4 или 7 без статуса «Студент» ведёт на экран `gate` с кнопкой в профиль.
- **Сохранение состояния сессии**: баллы ЕГЭ, введённая позиция в списке, результат теста, добавленные дедлайны и лайки живут между переходами.
- **Смена статуса** мгновенно перестраивает меню (блокировки), профиль (поле группы, блок верификации), календарь (события) и показывает тост.
- **Календарь**: клик по точке открывает шторку с событиями дня и обновляет крупное число + день недели; стрелки листают месяцы (в прототипе июнь → август 2026), при листании точки переигрывают анимацию появления.

### Анимации

| Имя | Значение | Где |
|---|---|---|
| `nvIn` | opacity 0→1, `translateY(12px)`→0, `.3–.4s ease` | вход экранов, карточек, тостов |
| `nvPop` | `scale(.2)`→1 + fade, `.34s cubic-bezier(.25,1.4,.45,1)` | точки календаря, stagger 12ms |
| stagger списков | 50–60ms между элементами | варианты теста, карточки вузов |
| шторка | `.42s cubic-bezier(.3,1.05,.4,1)` | открытие/закрытие |
| hover точки | `scale(1.16)`, `.2s cubic-bezier(.3,1.4,.4,1)` | календарь |

### Состояния интерфейса

- Hover светлых кнопок: `background: rgba(32,30,29,.06)`; pressed: `rgba(32,30,29,.12)`.
- Hover тёмных: `--color-neutral-800`. Hover акцентных: `--color-accent-400`; pressed: `--color-accent-700`.
- Focus-visible: `outline: 2px solid var(--color-accent); outline-offset: 2px` — **обязательно добавить в реализации**, в прототипе опущен.
- Disabled: `opacity: .45` либо серая заливка + `cursor: not-allowed` (кнопка подбора вузов).
- Ошибка ввода: обводка поля `--color-accent` + короткая подпись, без красного цвета.

### Данные из внешних источников (ТЗ, раздел 3 — только открытые данные)

- Блок 1: открытый API вакансий (счётчики по профилю).
- Блок 2: открытые данные приёмных кампаний прошлых лет (проходные баллы, бюджетные места, стоимость, общежитие, даты).
- Блок 3: открытые конкурсные списки вузов + планировщик push-уведомлений (за 7 дней до старта приёма, за 1 день до конца).
- Блок 4: списки групп вуза или ical/Moodle-календарь по ссылке; ежедневная сводка в заданное пользователем время.
- Блок 5: собственная база вопросов/ответов, верификация через учебную почту, push автору при ответе.
- Блок 7: картографический API (Яндекс.Карты / 2ГИС), геолокация вуза из профиля, глубокие ссылки на карточку места.
- Блок 8: пересылка обращения в закрытый чат администраторов + доставка ответа пользователю от обезличенного имени «Поддержка».
